# Carrowmont FRE Batch 3C — Ask Carrowmont Discoverability + UI Refinement

## Purpose
Refine the approved Batch 3B public Ask Carrowmont MVP after live visual review, without changing the five controlled journeys or any deterministic financial engine.

## Changes
- Compress the Ask Carrowmont first screen into an interactive workspace.
- Move the question input above the fold and keep five journey starters beside the primary action.
- Remove the oversized marketing hero and the separate right-side MVP explainer card.
- Add `Ask` to shared desktop navigation via `site.js`.
- Make `Ask` the center first-level mobile bottom-navigation action: `Home | Tools | Ask | Learn | More`.
- Keep Search in the mobile header so Search and Ask remain visibly different jobs.
- Move Research into the mobile More panel; do not duplicate Ask or Search inside More.
- Add one subtle homepage entry: “Not sure which tool you need? Ask Carrowmont”.
- Preserve the nine-card homepage core tool grid and 23-tool Tools Hub.
- Preserve the existing `/ask-carrowmont.html` URL, search inventory and sitemap entry.

## Product boundary
This is a discoverability and presentation refinement, not the Batch 11 homepage transformation. The homepage remains calculator-led and Ask Carrowmont remains an optional path.

## Calculation boundary
No financial formulas, routing rules, journey facts, assumptions, persistence rules, or engine adapters are changed. Existing Carrowmont deterministic engines remain authoritative.
