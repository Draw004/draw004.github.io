# CARROWMONT LEARN3D-2 — Financial Independence & Inflation Foundations

**Implementation baseline:** Carrowmont Source Snapshot 100  
**Implementation date:** 21 October 2026  
**Scope:** Eight existing Learn guides; no new public URLs.

## Purpose

LEARN3D-2 completes the approved LEARN3D programme by improving the financial-independence and inflation foundation guides. The release makes target, timing, Coast FIRE, purchasing power, future cost, savings erosion and today-vs-future-money concepts easier to apply without presenting a target, date, return, inflation rate or withdrawal assumption as a promise.

## Editorial improvements

Each page keeps its established canonical URL, H1 ownership and primary question. A separate `data-cm-learn3d2="1"` enhancement module adds one transparent worked illustration, a practical checklist and contextual links to the next relevant guide. Existing Learn V2 `data-cm-depth="1"` modules remain untouched and unique.

The release reinforces these distinctions:

- an FI number is a spending-based target, while the FI timeline is a path to that target;
- Coast FIRE is the present value of a future retirement target under assumptions, not permission to stop planning;
- a modeled FI crossing date is a milestone, not a forecast;
- purchasing power and future cost are opposite views of the same inflation relationship;
- a nominal savings balance can rise while real purchasing power falls;
- an inflation index is an average basket rather than every household's exact experience;
- today's-money and future nominal-money planning are both valid, but they must not be mixed silently.

## Localization

All new money examples use the existing Carrowmont declarative localization bindings. Values within each worked example stay on one proportional teaching basis when the selected currency changes. Currency presentation remains illustrative scaling, not live FX conversion.

Country-specific taxes, pensions, benefits, account wrappers and product rules remain outside the universal educational core.

Older active architecture remains authoritative:

- `when-can-i-reach-financial-independence.html` and `coast-fire-explained.html` keep the Financial Independence Planner at the top and shared bottom CTA;
- `inflation-value-of-money-over-time.html`, `future-cost-of-expenses.html`, `inflation-purchasing-power-savings.html` and `todays-money-vs-future-money.html` keep the Inflation Calculator at the top and shared bottom CTA;
- `inflation-purchasing-power.html` also keeps the Inflation Calculator as its primary tool journey;
- `financial-independence-number.html` keeps the distinct FI Number by Spending tool as its primary action.

No newer editorial recommendation silently overrides an older architectural contract.

## Search and indexing

No canonical URL is changed and no new public URL is created. Only these eight materially rewritten pages receive `dateModified` and sitemap `lastmod` of `2026-10-21`.

SEARCH1 remains at exactly 121 public entries. Eight reviewed query-intent groups and deterministic fixtures strengthen distinct ownership for FI target, FI timing, Coast FIRE, purchasing power, future expense cost, savings erosion, inflation foundations and money-basis queries without storing user queries or adding an external search service.

Search visibility is a desired outcome of better content. This release does not guarantee crawling, indexing, ranking, traffic or AI citation.

## Product boundaries

This release does not change calculator formulas, reports, PDF engines, shared-plan-state behavior, analytics, SEARCH1 query privacy, homepage core-tool architecture or workflow files.

LEARN3D is complete only after Publisher, live Automated QA and Multi-Repo Guard are green and a fresh post-release Source Snapshot is captured.
